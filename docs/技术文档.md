> 本文档基于对项目文件、配置与二进制的静态分析整理而成，用于说明《晴るる》作品的技术实现细节，便于他人理解、复用或继续迭代该项目。

## 一、技术概览

| 项目 | 内容 |
| --- | --- |
| 引擎版本 | **Unreal Engine 5.6**（`EngineAssociation: "5.6"`，资产标记 `Release-5.6`） |
| 项目内部名 | `Art` |
| 创建模板 | `TP_ME_BlankBP`（影视 / 虚拟制片「Blank」空白模板） |

| 图形质量 | Maximum（最高） |

> 项目通过 `ActiveGameNameRedirects` 从模板名 `TP_ME_BlankBP` 重定向为 `/Script/Art`，因此保留了虚拟制片模板自带的一整套 VP 插件。

### 启用插件（.uproject 中 Enabled）

- **渲染 / 输出**：`MovieRenderPipeline`（出图核心）、`SunPosition`（太阳方位）、`HDRIBackdrop`
- **虚拟制片**：`OpenXR`、`VirtualScouting`、`VirtualCamera`、`VirtualProductionUtilities`、`nDisplay`、`RemoteControl`、`Composure`、`LiveLink`
- **媒体 / 采集**：`MediaIOFramework`、`MediaFrameworkUtilities`、`AjaMedia`、`BlackmagicMedia`、`AppleProResMedia`、`HAPMedia`、`PixelStreaming`、`DMXProtocol`
- **脚本 / 流程**：`PythonScriptPlugin`、`SequencerScripting`、`Takes`、`VariantManager`
- **移动端**：`AppleARKit`、`AppleARKitFaceSupport`

> 其中与作品直接相关的是 `MovieRenderPipeline`、`SunPosition`、`HDDIBackdrop` 与 `SequencerScripting`；其余为 VP 模板默认启用。

## 三、资产制作管线

### 3.1 流程

```
Blender 建模（人物 / 伞 / 栅栏）
        │  导出
        ▼
FBX（.fbx 中间格式）
        │  Interchange 导入（UE5.6 默认导入管线）
        ▼
UE5 静态网格 + 材质（People / Umbrella）
```

- 角色与伞在 Blender 中建模后导出为 **FBX**，经 UE5.6 的 **Interchange** 管线导入。
- 材质在导入时由 `MF_PhongToMetalRoughness` 函数节点自动从传统 Phong 属性转换为金属 / 粗糙度工作流。
- 树木为 **Fab** 下载素材，以网格部件形式直接进入 `Tree/` 目录。

## 四、渲染与光照技术

配置来自 `Config/DefaultEngine.ini` 的 `[/Script/Engine.RendererSettings]`。

### 4.1 全局光照与反射

| 设置 | 值 | 说明 |
| --- | --- | --- |
| 动态全局光照 | **Lumen**（`DynamicGlobalIlluminationMethod=1`） | 实时间接光 |
| 反射 | **Lumen**（`ReflectionMethod=1`） | 实时反射 |
| 网格体距离场 | 开启（`GenerateMeshDistanceFields=True`） | Lumen 依赖 |
| 反射捕获分辨率 | 2048 | |

### 4.2 光追与阴影

| 设置 | 值 |
| --- | --- |
| 硬件光追 | 开启（`r.RayTracing=True`、`RayTracingProxies.ProjectEnabled=True`） |
| 虚拟阴影贴图（VSM） | 开启（`r.Shadow.Virtual.Enable=1`） |
| 皮肤缓存着色器 | 开启（`r.SkinCache.CompileShaders=True`，用于角色） |
| 镜头光晕 | 开启（`r.DefaultFeature.LensFlare=True`） |
| 天空大气影响高度雾 | 开启（`r.SupportSkyAtmosphereAffectsHeightFog=True`） |

| Bloom | 关闭 | |

| 锐化 | 2（`r.Tonemapper.Sharpen=2`） | |
| GBuffer 格式 | 3 | |

## 七、序列与摄像机（LS.uasset）

- `LS` 为 **Level Sequence**，内含 `CineCameraActor` 与 `CameraCutTrack`（镜头剪切轨）。
- 通过 `MovieSceneFloatTrack` 对以下摄像机属性做了关键帧控制：
  - **当前焦距**（`CurrentFocalLength`）
  - **当前光圈**（`CurrentAperture`）
  - **对焦设置 → 手动对焦距离**（`FocusSettings.ManualFocusDistance`）
- 这组轨道实现了「变焦 / 光圈 / 对焦」的影视级调校，是产生浅景深与主体聚焦的关键。

## 八、渲染输出（Movie Render Queue）

`EditorMoviePipelineQueue.uasset` 记录了出图队列配置：

| 配置项 | 内容 |
| --- | --- |
| 输出设置 | `MoviePipelineOutputSetting`，正方形输出 |
| 抗锯齿 | `MoviePipelineAntiAliasingSetting`（**空间采样 SpatialSampleCount + 时间采样 TemporalSampleCount**） |
| 图片序列输出 | `MoviePipelineImageSequenceOutput_PNG` 与 `MoviePipelineImageSequenceOutput_JPG`（两者均配置） |
| 控制台变量覆盖 | `r.VolumetricCloud.ReflectionRaySampleMaxCount`、`r.VolumetricCloud.SkyAO.TraceSampleCount`（提升体积云质量） |
| 关联关卡 / 序列 | `/Game/Main`、`/Game/LS` |

### 成片规格

- 分辨率：**2048 × 2048**
- 格式：**8-bit RGBA PNG**
- 数量：4 张（`0.png`、`1.png`、`1-fix.png`、`2.png`）

## 十、补充说明（基于分析的推断）

以下为从文件内容推断、非作者口头确认的结论，供参考：

1. **模板来源**：工程由 VP「Blank」模板派生（模板名重定向证据），因此携带大量虚拟制片插件，其中多数与本作品无关。
2. **两版伞模型**：`Umbrella.blend`（308 KB）与 `Umbrella_J.blend`（1.6 MB）并存，后者体积更大，推测为更精细 / 最终的伞模型版本。
3. **伞柄材质**：`Umbrella/Handle` 的材质槽位指向引擎默认 `WorldGridMaterial`，推测该部件未指定最终材质，或仅用于 UV / 结构占位。
4. **`1-fix.png`**：文件名暗示机位 2 经过一次修正后重新渲染，为迭代产物。
5. 精确的太阳方位角、雾密度、后处理曝光值等数值存储于 `Main.umap` 的二进制属性中，需在 UE 编辑器中打开关卡才能获得精确值。
