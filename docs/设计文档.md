# 设计文档 ·《晴るる》UE5 场景再现

> 作品名称：晴るる（はるる）
> 灵感来源：日本乐队 あたらよ（Atarayo）歌曲《晴るる》专辑封面
> 制作工具：Blender（建模）＋ Unreal Engine 5.6（场景 / 光照 / 渲染）
> 作品用途：个人作品集（Portfolio / Gallery）

---

## 一、项目概述

本作品是一次 **「从 2D 插画到实时 3D」的视觉转译练习**。以日本乐队 あたらよ 的歌曲《晴るる》专辑封面为蓝本，使用 Blender 自行建模核心资产（人物、透明伞、栅栏等），再从 Fab 获取植物素材，最终在 Unreal Engine 5.6 中完成场景搭建、天气与光照调试，并用影视级摄像机（CineCamera）＋ Movie Render Queue 输出高质量静帧。

作品定位于**单帧静帧渲染**（非可交互游戏），核心目标是还原专辑封面中「雨过天晴」的清新、明亮与治愈情绪。

---

## 二、灵感来源与参考

### 2.1 歌曲与封面

- **《晴るる》** 是乐队 あたらよ 的作品，歌名「晴るる」意为**「放晴、雨过天晴」**。
- 专辑封面以「**少女 + 透明伞 + 湛蓝晴空 + 白云**」为核心意象，整体色调明亮、通透，情绪上带有雨后初晴的清爽与淡淡的青春感。

## 三、设计目标

1. **情绪还原**：抓住「晴るる」放晴后的明亮、通透、治愈氛围。
2. **跨媒介转译**：把 2D 插画的造型与配色，转化为在实时引擎中可成立的三维场景。
3. **灯光叙事**：利用太阳角度、天空大气与体积云，讲出「雨刚停、天刚晴」的时间点。
4. **影视感呈现**：用物理摄像机（焦距 / 光圈 / 对焦）与后期调色，逼近摄影而非「游戏截图」的观感。

---

## 四、视觉设计

### 4.1 角色

- 在 **Blender** 中建模的人物模型，作为画面的视觉焦点与情绪载体。
- 造型、发色与服装均以参考图 `Character.png` 为依据，强调与原画的相似度。
- 在 UE 中为角色启用了 **皮肤缓存着色器（Skin Cache）**，以提升皮肤与头发的渲染质感。

### 4.2 道具：透明伞

透明伞是封面最具辨识度的符号，也是本作的核心道具。伞被拆分为两个独立部件：

- **伞面（Face）**：使用**半透明材质**，让天光与云影可穿透伞面，形成「透过透明伞看天空」的通透感——这是还原原画情绪的关键。
- **伞柄 / 伞骨（Handle）**：承载结构轮廓。

伞的源文件包括 `Umbrella.blend` 与更精细的 `Umbrella_J.blend` 两个版本，最终导出为 `Umbrella.fbx`。

### 4.3 道具：栅栏

- 在 Blender 中建模的**栅栏**，用于建立画面近景的纵深层次，并强化「室外 / 街道 / 学校附近」的场景语境。
- 栅栏作为前景或中景元素，与远景的天空、花树形成空间层次。

### 4.4 场景植被：蓝花楹（Jacaranda）

- 树木素材来自 **Fab**（原 Quixel/Marketplace）下载的**蓝花楹（Jacaranda）**，其紫色花序与「放晴」的明亮天空形成冷暖对比，是画面中最重要的色彩点缀。
- 素材被拆分为多个部件（树冠 2K 主体、树干、树枝、树叶），便于在场景中灵活摆放与调整疏密。

### 4.5 天空与天气

- 通过 UE5 的 **Sky Atmosphere（天空大气）＋ Volumetric Cloud（体积云）** 构建「放晴的蓝天 + 白云」。
- 云使用了**自定义云材质**（`m_CustomCloud`，基于引擎 `m_SimpleVolumetricCloud` 派生的材质实例），并对云的全局覆盖率、密度、反照率颜色等参数做了定制，使云层形态更贴合参考封面。
- 启用**体积雾（Volumetric Fog）**，让地面与远景之间的空气产生微妙的纵深与光尘感。

### 4.6 光照

- 主光源为**定向光（DirectionalLight，即太阳）**，结合 **Sun Position 插件**精确控制太阳方位与时间点，还原「雨过天晴」的日照角度。
- 配合 **SkyLight（天空光）** 提供来自天空的柔和环境照明，使阴影通透、不显死黑。
- 全局光照采用 **Lumen**，让天空光、云影与花树在场景中产生自然的漫反射与间接光。

### 4.7 色调与后期

- 项目**关闭了自动曝光与运动模糊、Bloom**，转而采用更可控的手动曝光与调色，逼近摄影棚/实拍的照片感。
- 通过 **PostProcessVolume（后处理体积）** 对曝光与整体影调做精细控制，统一最终画面的明暗与色彩倾向。
- 画面整体倾向**高明度、低饱和、偏冷蓝 + 紫色点缀**的清新色调，与「放晴」主题一致。

---

## 五、镜头与构图设计

- 使用 **CineCameraActor（电影摄像机）** 而非默认镜头，以获得物理相机的真实光学特性。
- 在 **Level Sequence（关卡序列）** 中为摄像机设置了**焦距（Focal Length）、光圈（Aperture）与手动对焦距离（Manual Focus Distance）** 轨道，用浅景深突出人物主体、虚化背景花树与天空。
- 本作共设计了 **多个机位**，从不同景别（近景 / 中景）与角度诠释同一场景，对应最终输出的多张成片。

---

## 七、作品小结

《晴るる》以一张专辑封面为起点，经历了 **Blender 手工建模 → Fab 素材整合 → UE5 光照天气搭建 → 影视摄像机取景 → 高质量静帧输出** 的完整流程。作品的价值不在于「复刻」原画，而在于用实时渲染的手段，把插画中的光线、空气与情绪**重建为一个可环视、可重新构图的真实三维世界**。
